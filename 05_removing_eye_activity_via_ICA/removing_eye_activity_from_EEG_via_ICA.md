# 变式总结

参考 `eog_ica_annotated.py` 的迁移任务，当前代码完成了 EOG 辅助筛选与可视化复核：

1. 使用 `EOG1`，通过 `find_bads_eog` 按相关性阈值 `0.5` 获取候选成分，并用 `plot_scores` 查看得分。
2. 属性图查看成分 `[1, 7, 8]`，结合头皮分布、分段图、频谱和时间波形复核眼电特征；这些查看编号不等于排除编号。
3. 初始排除列表为 `[1]`，EOG 候选不自动写入排除列表，成分浏览器中可进一步调整。
4. 在 1 Hz 高通副本上拟合 ICA，应用于原始数据副本，再查看处理前后波形。

目前以定性检查为主，尚未加入事件对齐、眨眼峰峰值减幅计算，以及无明显眼动片段的波形与频谱保留检查。

# 适用问题

1. 从脑电信号中减弱眼电伪迹，保留原始记录供对照。

# 理论模型

1. 技术路线

```text
原始 EEG → 1 Hz 高通副本 → Picard ICA
        ↓ EOG 相关性与可视化复核
确定排除成分 → 在原始副本上重建 → 比较处理前后波形
```

2. 眼球活动和眨眼产生的电信号会混入 EEG，常在额区较明显，并可能传播到多个通道；它们往往幅度较大、低频能量较强。
3. ICA 将多通道混合信号分解为成分；排除的是指定成分对 EEG 的贡献，不是删除电极。统计独立不等于已证明该成分只来自眼睛。

# 机制理解

1. `plot_components()` 查看成分的头皮分布，额区投影可作为眼电线索，成分编号靠前本身不是删除依据。
2. `find_bads_eog()` 提供与 EOG 同步变化的外部线索，候选成分仍需人工复核。
3. `plot_properties()` 显示分段图与频谱：缓慢、大幅、持续色块可能对应眼动，快速密集变化可能含肌电；颜色与形状本身不能确定来源。
4. 低频高峰、缺少明显 8～40 Hz 节律峰，以及 `plot_sources()` 中偶发大波峰都可辅助判断，需结合空间分布和 EOG，不能单独作为结论。

# 操作技巧

1. ICA 拟合前在副本上高通以减轻慢漂移影响；重建使用本脚本未额外高通的原始副本。
2. 显示时窗应足以覆盖关注的慢变化，可从若干完整周期开始观察，再根据实际记录调整。
3. 非交互诊断图可用 `show=False` 创建后统一 `plt.show(block=True)`；成分浏览器需等待关闭后再重建。

# 工程理解

1. `float64` 约有 15～16 位十进制有效精度，适合一般数值分析；数据规模和计算成本较高时可评估 `float32`，`float16` 不宜随意用于这些预处理计算。
2. 当前 `[1]` 是本记录的复核起点，换数据或软件版本后不能照搬成分编号；误排除也可能损失脑活动。
3. 本脚本不输出量化的清理指标，不能仅凭波形变小断言清理完全成功。

# 编程细节

1. MAT 的 `X` 为 `(采样点数, 通道数)`，乘 `1e-6` 并转置后交给 RawArray；通道类型必须与名称及数据列对应。
2. 部分末尾带 `_` 的 MNE 属性表示拟合后生成的结果，例如 `ica.n_components_`。
3. 三维体数据常采用 `(z, y, x)`，但这不是所有 NumPy 数组的通用轴约定，应以具体数据接口为准。

# 错误纠正

1. EEG/EOG 类型配错时，`set_montage()` 会按错误的类型匹配位置，可能报错。
2. `[1, 7, 8]` 是诊断图查看列表；真正参与重建的是当时的 `ica.exclude`。
3. `rng=1` 不应随意替换为 `random_state=1`，两者使用的随机数序列不同。
