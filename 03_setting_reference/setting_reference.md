# 变式总结

对照 `55_setting_eeg_reference_annotated (2).py`，当前主脚本以 REST 对照为默认实验：

1. 选取前 60 秒的 `EEG 041～059`，补回全零参考通道 `EEG 999`，使用球模型、源网格和前向模型计算 REST，并与原始参考波形比较。
2. 将原来注释中的三个顺序方案整理为 `compare_average=True` 可开启的实验：先删道再平均、先平均再删道、先建投影再删道并应用。删除范围仍为 `EEG 041～049`，没有照搬迁移任务的三个删道编号。
3. 默认不执行该平均参考实验；尚未加入迁移任务要求的逐时刻均值残差、B/C 数值一致性和电极差分验证。

# 适用问题

1. 改变 EEG 的参考定义，减少对单个参考电极的依赖，并满足后续分析的参考要求。
2. 理解删减通道为何会影响平均参考，以及延迟应用投影的作用。

# 理论模型

1. 技术路线

```text
sample EEG → 前 60 秒、EEG 041～059
        ↓
补回参考通道；可选比较删道与平均参考的顺序
        ↓ 球模型 → 源网格 → 前向模型
REST 重参考 → 与原始参考波形对照
```

2. 常规重参考为 $y_i(t)=x_i(t)-r(t)$。参考变化是所有参与通道共享的偏移，两通道之间的电位差仍可保留。

| 方法 | 主要特点 | 适用与局限 |
| --- | --- | --- |
| 单电极参考 | 简单，减去指定电极的信号 | 临床等常用；参考噪声可传播到其他通道 |
| 平均参考 | 减去有效电极的瞬时均值 | EEG/BCI 常用；受电极覆盖和有效通道集合影响 |
| REST | 根据前向模型估计无穷远参考 | 依赖电极位置、头模型和源模型，模型误差会影响结果 |
| 双极导联 | 计算指定电极对的差分 | 便于观察局部差异；依赖配对，不保留原来的单通道表示 |

# 机制理解

1. 平均参考减去共享均值，可能减弱共同干扰，也可能包含真实脑活动，不能等同于自动去噪。
2. 先做数值平均参考再删道，已减去的参考不会自动重算；先删道再平均，使用的是保留通道的均值。
3. 平均参考投影器保存尚未应用的变换，删道后再 `apply_proj()` 可按当前通道集合构造参考。`plot(proj=True)` 只用于显示预览，不等于已修改存储的波形。

# 操作技巧

1. 先确认通道名称、坏道名单和电极坐标；对不同参考方案使用独立副本。
2. 比较参考效果时固定显示尺度，避免把自动缩放误认为振幅变化。

# 工程理解

1. 全零旧参考通道表示“旧参考相对于自身的电位差为零”，不是恢复了一条原先测量但丢失的信号；不能给任意缺失电极补零。
2. 将确认缺失的旧参考补回，才能在新参考下表示它的相对电位；若希望它参与平均，需在重参考前添加。
3. REST 本例使用自动球心与半径、`15 mm` 源网格、排除球心 `30 mm` 范围；这是教学模型，不是个体 MRI 源定位流程。

# 编程细节

1. Raw 同时保存通道数据和类型标签，`pick()` 可按名称或类型选择，且会原地修改对象。
2. `add_reference_channels()` 默认返回副本；`set_eeg_reference()` 的 Raw 方法会修改它作用的对象。
3. `apply_proj()` 会应用对象中可用的投影器；比较参考前需区分平均参考投影与其他 SSP。主脚本移除未应用的旧投影，避免额外变换混入对照。

# 错误纠正

1. 先查看 `raw.ch_names`，不要假设不同数据集的编号规则相同。
2. 原脚本的 Original/REST 标题与数据配对反了，现已对应正确。
3. 延迟投影与已执行的参考减法要区分：前者可在应用时反映通道变化，后者不会因删道自动更新。
