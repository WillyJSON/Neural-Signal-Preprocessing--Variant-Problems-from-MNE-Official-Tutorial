# 变式总结

本目录没有提供 `annotated.py`，以下总结当前代码的实操内容，不推定相对某个教程的差异：

1. 使用 MOABB 读取 BNCI2014_001，默认只读取被试 1 的 `0train` 会话、第 0 个 run，不执行分类评估。
2. 选取 `C5`、`C3`、`C1`，将前 10 秒的波形换算为微伏，按通道分别绘制。
3. 对同一记录的前 30 秒计算 Welch 功率谱，查看 4 Hz 至奈奎斯特频率的频率分布。

# 适用问题

1. 认识连续神经电信号的组织形式，完成数据读取、选道和基础可视化。

# 理论模型

1. 技术路线

```text
读取指定被试 / 会话 / run
        ↓ 选择 C5、C3、C1
前 10 秒波形 → 单位换算后绘图
前 30 秒记录 → Welch 功率谱 → 查看频率分布
```

2. 实验数据常按 subject / session / run / trial 四个层级组织：session 是一次采集会话，run 是会话内的一段记录，trial 对应一次任务。连续 Raw 尚未按 trial 分段。
3. 时间轴与通道轴的顺序取决于对象；MNE `Raw.get_data()` 返回 `(通道数, 采样点数)`。
4. 功率常用分贝表示：$P_{dB}=10\log_{10}(P/P_{ref})$。对数尺度便于同时观察相差较大的功率，参考量及单位仍需看图轴说明。

# 机制理解

1. 波形图回答“信号随时间怎样变化”，功率谱回答“能量分布在哪些频率”。
2. Welch 将记录切成若干段，分别估计功率谱后平均，以减小单次估计的波动。

# 操作技巧

1. 先查看 `raw.info`，确认通道名称和采样率，再选择时间范围。
2. 显示单位换算只用于绘图；MNE 内部 EEG 数据仍以伏特保存。

# 工程理解

1. 设置数据集的被试列表不等于已读取全部被试；实际读取范围由 `get_data(subjects=...)` 决定。
2. 本脚本只做数据认识与可视化，不包含 CSP、分类器或交叉验证。

# 编程细节

1. `raw.times` 的单位为秒，`get_data(start, stop)` 使用采样点索引；秒数需乘以 `sfreq`。
2. `copy().pick().crop()` 在副本上选择通道和时间范围，保留原记录。
3. `show_plots=False` 时仍读取数据并计算功率谱，但不创建图窗。

# 错误纠正

1. 图标题应使用实际被试编号，不能读取被试 1 却标为被试 3。
2. 高通保留较高频率，低通保留较低频率；这与波形振幅大小无关。
