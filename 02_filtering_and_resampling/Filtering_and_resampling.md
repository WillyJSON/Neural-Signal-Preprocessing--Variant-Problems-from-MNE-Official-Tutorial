# 变式总结

相对 `mne_filtering_resampling_annotated_v2.py` 的带通、陷波和重采样流程，主脚本将重点改为低频漂移与工频谐波：

1. 只处理磁强计和刺激通道，用 `0.33 Hz` 高通替代参考脚本的 `1～40 Hz` 带通；滤波后查看前 60 秒。
2. 对 `60、120、180 Hz` 做陷波，分别设置宽度 `0.2、0.23、0.33 Hz`，过渡带参数为 `0.1 Hz`。
3. 保留独立的高通和陷波副本，用波形及 Welch 功率谱比较处理结果。整理时改用前 120 秒作为滤波输入，避免窄过渡带滤波器长于原来的 60 秒片段；没有执行参考脚本的 `200 Hz` 重采样。

# 适用问题

1. 滤波：减弱低频漂移、高频噪声及工频干扰，保留研究关注的频率范围。
2. 重采样：在时间精度与目标频段允许时降低数据量，或统一不同记录的采样率；当前主脚本未执行这一步。

# 理论模型

1. 技术路线

```text
sample 连续记录 → 前 120 秒磁强计与刺激通道
        ↓ 0.33 Hz 高通
高通副本 → 60 / 120 / 180 Hz 陷波副本
        ↓
截取前 60 秒 → 查看波形与陷波前后功率谱
```

2. EEG 与 MEG 的测量量不同，显示单位不能混用。

| 类型 | 测量量 | 常见显示单位 |
| --- | --- | --- |
| EEG | 相对于参考的头皮电位差 | μV |
| 磁强计 | 磁场强度 | fT |
| 梯度计 | 磁场的空间梯度 | fT/cm |

3. 神经信号背景谱常近似 $P(f)\propto 1/f^\alpha$，膜与突触动力学、信号同步程度等会影响频谱。它也可叠加节律峰和噪声峰，不能要求整条频谱严格递减。
4. 电源噪声常在 50 或 60 Hz 出现；畸变的周期信号还可能含整数倍谐波。陷波频率应根据实际频谱选择。
5. 降采样后的奈奎斯特频率为新采样率的一半，需要抗混叠处理；滤波改变频率内容，重采样改变时间采样间隔。

# 机制理解

1. 陡峭跳变可同时含低频和高频：高频贡献快速边缘，低频贡献较慢的持续变化。
2. 背景谱上的狭窄尖峰，尤其同时出现整数倍频率时，可作为外部周期干扰的线索。
3. FIR 使用输入信号的有限历史，易设计线性相位，但窄过渡带往往需要长滤波器，增加计算量和边缘影响。
4. IIR 还使用过去的输出，低阶即可形成较陡截止；需关注稳定性、相位和振铃。相位影响还取决于实际采用的单向或双向滤波方式。
5. `spectrum_fit` 通过时间窗中的周期成分估计并去除干扰；FIR/IIR 则抑制目标频段。前者可用于较清晰的线谱，不能仅凭“稳定或不稳定”断言哪种方法必然更好。
6. Welch 的分段越长，通常频率分辨率越高，但可平均的段数更少；短段则相反。增加重叠可增加段数，但这些段并不独立，50% 是常见起点。

# 操作技巧

1. 先确定目标频段，再查看采样率、已有高低通设置和实际频谱。
2. 优先排查偏离同类通道的坏道；低频异常抬升可考虑高通，工频窄峰可考虑陷波。
3. 若高频并非目标，可考虑低通；若高频本身有研究意义，应针对坏道、肌电等伪迹处理，必要时拒绝受污染片段或复核 ICA 成分。
4. 保留原始副本，查看足够长的时间段，避免把半周期误认作完整周期。
5. 陷波也会影响邻近的真实信号；干扰不明显时，不必机械地对每个谐波都陷波。

# 工程理解

1. 很窄的过渡带会生成较长的 FIR。本例保留 `trans_bandwidth=0.1` 的设置，在前 120 秒上滤波后裁剪到 60 秒；增加上下文可减轻截断造成的边缘影响，但不能完全消除记录起点的边缘效应。
2. `spectrum_fit` 的 `filter_length` 越长，估计通常更稳定，但追踪随时间变化的能力下降；越短则相反。
3. 工频频率取决于采集环境，不应只根据代码运行所在地选 50 或 60 Hz。
4. EEG/MEG 具有较高时间分辨率，但采样率并不等于有效时间精度；是否降采样仍取决于目标频段与分析需求。

# 编程细节

1. `raw.filter()`：`l_freq` 为高通边界，`h_freq` 为低通边界；过渡带、`method`、`filter_length` 控制滤波器设计，`picks` 选择处理通道。
2. `raw.notch_filter()`：`freqs` 指定中心频率，`notch_widths` 指定宽度，`trans_bandwidth` 指定过渡带参数；它会原地修改对象，需先 `copy()`。
3. `compute_psd()`：`method`、`fmin/fmax` 指定方法和范围；Welch 的 `n_per_seg`、`n_overlap`、`n_fft` 分别控制分段、重叠和频率网格，均按采样点设置。更密的 FFT 网格不等于更高的真实分辨率。
4. `tmin/tmax` 与 `picks` 控制分析时间和通道；Welch 的时间段平均与 `Spectrum.plot(average=True)` 的通道平均是两件事。
5. SSP 根据空间方向构造投影以减弱特定干扰；`proj=False` 不额外启用显示投影，`remove_dc=False` 保留显示窗口中的偏移。已应用到数据的处理不能靠这些选项撤销。
6. 示例数据入口在 `mne.datasets`；`sfreq` 表示采样率。`crop()`、`pick()`、`load_data()` 是 Raw 方法，`mne.pick_types()` 返回通道索引。

# 错误纠正

1. `average=False` 不是 Welch 的合法平均选项；主脚本使用默认的时间段平均，绘图时再平均通道。
2. 高通边界叫 `l_freq`，低通边界叫 `h_freq`，不要按中文词面反配。
3. 低于 `0.1～0.2 Hz` 不一定全是伪迹，`0.5～4 Hz` 也不能自动视为正常活动，需结合采集与研究目的判断。
4. 区分采样的奈奎斯特频率与数据已有的低通截止；二者不是同一概念。
