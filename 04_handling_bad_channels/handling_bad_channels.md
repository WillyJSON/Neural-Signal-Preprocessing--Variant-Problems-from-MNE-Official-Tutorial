# 变式总结

相对 `handling_bad_channels_annotated.py`，当前主脚本主要比较“多标坏正常 EEG 通道”对插值的影响：

1. 保留文件原有坏道，另把 `EEG 051、052、053` 纳入对照名单，对前 3 秒 EEG 分别插值。
2. 对照插值前、原坏道名单插值后、额外标坏后插值的 `EEG 050～059` 波形；保留坏道标签以便观察。
3. 原来注释中的未标记、原名单、额外标坏三组 Epochs/Evoked 对照，整理为 `compare_evoked=True` 的可选实验，默认不执行。

这与迁移任务“隐藏一条正常通道并用实测波形评价误差”不同；当前未计算相关系数、RMSE，也未比较两种 `reset_bads` 设置。

# 适用问题

1. 记录异常通道并控制后续操作是否使用它们；需要保留布局时，依据正常通道估计坏道信号。
2. 观察误把正常通道标坏后，插值结果及后续选道怎样变化。

# 理论模型

1. 技术路线

```text
读取 sample 与原坏道名单 → 创建额外标坏的副本
        ↓ 前 3 秒 EEG，保留待修复通道
两份名单分别做球面样条插值 → 固定尺度比较波形
可选：同一事件分段 → 平均响应 → 查看坏道标签传递
```

2. 标记只修改 `info["bads"]`，排除决定某次操作使用哪些通道，插值才会改写估计出的信号。
3. EEG 测量电位差，磁强计测量磁场强度，梯度计测量磁场的空间梯度；不能仅凭传感器类型断言其专门保留深部信号或直接代表异常。
4. `Epochs.average()` 对同类事件的试次在各通道、各相对时刻上求平均，用于估计事件相关响应，不是在通道之间取平均。

# 机制理解

1. EEG 球面样条利用正常电极的信号和空间位置估计坏道；额外标坏会减少可用供体，并改变被重建的通道集合。
2. 插值恢复通道数量，不等于恢复同样数量的独立测量信息；波形更平滑也不等于更接近真实信号。
3. `reset_bads=False` 保留标签，但插值仍已执行；后续默认排除坏道的操作仍可能跳过这些通道。

# 操作技巧

1. 比较同类型、邻近位置的通道，检查持续平直、异常幅度和噪声；编号相近不保证位置相邻，单次大振幅也不足以认定坏道。
2. 检查波形时可用 `proj=False`，避免尚未应用的 SSP 在显示中掩盖异常；MEG 梯度计也可作为检查对象。
3. 插值对照使用相同时间段和尺度，保存原名单，避免为了实验覆盖真实坏道记录。

# 工程理解

1. 插值需要正确的电极或传感器几何信息；本示例 FIF 已包含坐标，不必硬套其他标准布局。
2. Epochs/Evoked 继承创建时的坏道标签，后来修改 Raw 不会追溯同步它们。
3. 标记本身不会修复其他通道；但它会影响后续参考、空间处理和绘图选择，因此影响不只限于插值。

# 编程细节

1. `Raw.plot()` 的 `n_channels` 控制同屏数量，`bad_color` 控制坏道颜色，`theme="light"` 可固定浅色背景。
2. `mne.pick_types(..., exclude="bads")` 返回正常通道的整数索引；`exclude=[]` 可保留坏道。
3. `Raw.pick()` 返回并原地修改 Raw 对象，不返回通道名称列表；名称在 `.ch_names` 中。按类型选道时需明确是否排除坏道。
4. `load_data()` 载入波形，`get_data()` 取出 NumPy 数组；`info["bads"]` 本身是可修改的名称列表。

# 错误纠正

1. `pick()`、`crop()` 和 `interpolate_bads()` 会原地修改对象，需按对照目的先 `copy()`；`compute_psd()` 返回 Spectrum，并不会因此改写 Raw 波形。
2. 额外标记应保留已有坏道，不能把新增名单直接当作全部名单覆盖。
3. 从平均图中隐藏一个坏道，不代表其余通道已被清理或修复。
